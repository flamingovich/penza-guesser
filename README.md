# PenzaGuesser

Локальная игра в стиле GeoGuessr на панорамах Яндекса, только по Пензе.

## Запуск

1. Двойной клик по `start.bat` (нужен Python) — откроется http://localhost:8765/ (сервер `serve.py`, без кэша).
   Открывать именно через `localhost` — ключ ограничен по HTTP Referer.
2. Один раз вставить в меню API-ключ Яндекс Карт: https://developer.tech.yandex.ru/services/ →
   «Подключить API» → «JavaScript API и HTTP Геокодер». Ключ можно также прописать в `config.js`.

## Лимит бесплатного ключа

Бесплатный тариф — 100 запросов в сутки. На практике на раунд уходит около одного запроса, шаги по стрелкам в лимит не идут.
Поэтому старт выбирается на случайной точке дороги (`js/roads.js`, улицы из OpenStreetMap), и панорама
находится обычно с первого запроса. Внизу меню виден счётчик поисков и переходов за день; точный расход —
в кабинете Яндекса → «Статистика». Регулярное превышение лимита Яндекс может наказать блокировкой ключа.

## Очки (как в GeoGuessr)

`очки = 5000 · e^(−10 · d / размер_карты)`, где `d` — промах в метрах, а размер карты — диагональ
прямоугольника вокруг Пензы (~21,7 км). Ближе 25 м — всегда 5000. Раундов 5, максимум 25 000.

| промах | очки |
|-------:|-----:|
| 25 м   | 5000 |
| 100 м  | 4775 |
| 500 м  | 3973 |
| 1 км   | 3156 |
| 3 км   | 1258 |
| 10 км  | 50   |

## Где

- **Город** — точки, рядом с которыми (250 м) есть хотя бы 3 многоэтажки или общественных здания по OSM: центр, Арбеково, Северная Поляна, Терновка.
- **Вся Пенза** — любая улица внутри контура, включая частный сектор, бывшие деревни и объездную.
- **Частный сектор** — только точки без многоэтажек рядом.

## Режимы

- **Можно ходить** — стрелки переходов, R — вернуться на старт.
- **Без ходьбы** — стоишь на месте, можно крутить и приближать.
- **NMPZ** — один кадр, без поворота и зума.

Подписи Яндекса на панораме (номера домов, адрес, название места, кнопка «Открыть в Яндекс Картах») скрыты,
в том числе после переходов по стрелкам. Таблички и вывески на самих снимках остаются. Граница города — `js/penza.js`.

## Данные

Точки на улицах в `js/roads.js` взяты из OpenStreetMap (© участники OpenStreetMap, лицензия ODbL). Панорамы и карты — API Яндекс Карт.
